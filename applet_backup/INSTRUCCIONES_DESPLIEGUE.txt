GUÍA PARA DUMMIES: DE GOOGLE AI STUDIO A PRODUCCIÓN (FIREBASE)
================================================================

¡Felicidades! Tienes una app increíble. Ahora vamos a sacarla de la simulación y ponerla en el mundo real.

FASE 1: PREPARAR TU ORDENADOR (EL TALLER)
-----------------------------------------
1. Descarga e instala VS Code: https://code.visualstudio.com/
2. Descarga e instala Node.js (versión LTS): https://nodejs.org/
3. Crea una carpeta en tu escritorio llamada "aulainfinity".
4. Copia TODOS los archivos de este proyecto dentro de esa carpeta.

FASE 2: CREAR EL "CEREBRO" EN LA NUBE (FIREBASE CONSOLE)
--------------------------------------------------------
1. Ve a https://console.firebase.google.com/ e inicia sesión.
2. Crea un nuevo proyecto llamado "aulainfinity-app".
3. Menú izquierdo -> Compilación -> Authentication:
   - Dale a "Comenzar".
   - Activa "Correo electrónico/Contraseña".
4. Menú izquierdo -> Compilación -> Firestore Database:
   - Dale a "Crear base de datos".
   - Elige ubicación (ej. eur3 para Europa).
   - Comienza en "Modo de prueba" (luego lo aseguras).
5. **IMPORTANTE:** Cambia al Plan Blaze (Pago por uso).
   - Necesario para que funcione la IA (Cloud Functions).
   - Clic en el engranaje -> Uso y facturación -> Detalles -> Cambiar a Blaze.
   - (Google da una capa gratuita, pero requiere tarjeta).

FASE 3: CONECTAR TU PC CON LA NUBE
----------------------------------
1. Abre VS Code en tu carpeta "aulainfinity".
2. Abre la terminal (Menú Terminal -> New Terminal).
3. Escribe estos comandos (uno a uno):
   
   npm install -g firebase-tools
   firebase login  (inicia sesión con tu Gmail)
   firebase init

4. En el asistente de 'firebase init':
   - ¿Qué quieres configurar?: Selecciona con espacio: Firestore, Functions, Hosting, Emulators. Enter.
   - Project Setup: "Use an existing project" -> Elige el que creaste en la FASE 2.
   - Firestore: Dale a Enter a todo.
   - Functions: Elige TypeScript -> Yes (ESLint) -> Yes (Install dependencies).
   - Hosting:
     - Public directory: escribe "dist"
     - Configure as single-page app?: Yes
     - Automatic builds?: No

FASE 4: CONFIGURAR LA LLAVE MAESTRA (API KEY)
---------------------------------------------
No pongas tu API Key en el código. Guárdala en el servidor seguro de Firebase:

1. Consigue tu API Key de Google AI Studio.
2. En la terminal de VS Code:
   
   cd functions
   firebase functions:config:set gemini.key="PEGA_AQUI_TU_API_KEY_LARGA"
   cd ..

FASE 5: EL CAMBIO DE CABLES (DE MOCK A REAL)
--------------------------------------------
Ahora mismo la app usa datos falsos. Vamos a conectarla de verdad.

1. Configurar credenciales:
   - Ve a Firebase Console -> Engranaje -> Configuración del proyecto.
   - Abajo, en "Tus apps", crea una app Web (icono </>).
   - Copia el objeto `firebaseConfig`.
   - Abre el archivo `src/services/firebase.ts` en tu PC y pega tus datos reales.

2. Apagar la simulación:
   - Abre `src/services/api.ts`.
   - Verás que importa `mockDatabase`.
   - Tienes que cambiar las funciones para que usen `db.collection(...)` (Firestore) y `functions.httpsCallable(...)` (para la IA) en lugar de `mockApi`.
   - *Nota:* Si esto es muy difícil al principio, puedes saltártelo y desplegar primero con los datos falsos para probar.

FASE 6: ¡LANZAMIENTO!
---------------------
En la terminal de VS Code:

1. Instalar librerías:
   npm install

2. Construir la web optimizada:
   npm run build

3. Subir a internet:
   firebase deploy

¡Listo! La terminal te dará una URL (ej. https://aulainfinity-app.web.app). Esa es tu web real.

FASE EXTRA: ADMIN
-----------------
1. Entra en tu web real y regístrate.
2. Ve a Firebase Console -> Firestore.
3. Busca tu usuario en la colección "users".
4. Cambia el campo "role" de "student" a "admin".
5. Recarga la web. ¡Ya eres el jefe!
